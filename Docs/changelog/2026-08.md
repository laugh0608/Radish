# 2026 年 8 月开发日志

## 本月摘要

- `2026-08-03` 完成 family-ui `v26.7.3` 破坏性基线升级：完整复核新版规范、token 与参考索引，确认 27 张参考图仅迁址且 Git blob 全部 `R100` 相同；同步 CSS / JSON 上游副本，新增 `text-on-brand`，并在 Radish 项目主题层显式保留 `guofeng` 胭脂品牌和四主题品牌前景。现有品牌 / 操作变量使用差异进入 `R1-F01` 代表设计裁决，本批未机械替换页面样式，也未启动服务或执行真实 smoke。
- `2026-08-03` 创建唯一活动设计源 `radish-web-family-ui-v1.pen`，以主版本号管理结构升级，普通迭代由 Git 留存；原四个大型 `.pen` 保持原样并转为只读留档。新文件已建立索引、可复用组件和 `R1-F01`，覆盖四主题矩阵、品牌 / 操作语义、控件、状态槽与 PC / 390px mobile 壳层。
- `2026-08-03` 形成 `R1-P01` 两轮 Public 内容流评审稿并完成独立 PC、390px mobile、关键状态和标题约束治理，但两轮均未通过业务页面审核。第二轮已分开分类、`#标签` 与结构化状态，仍因帖子占据绝大多数篇幅、全宽分类浏览笨重、构图偏离参考 `13 / 16 / 18 / 27` 而被否决；现有稿只由 Git 留档，不进入实现。国风灰玉 `#5d6c57` 与墨蓝操作 `#435c74` 的颜色目标继续保留，当前运行时旧胭脂值不提前修改。
- `2026-08-04` 完成参考 `13 / 16 / 18 / 27` 结构转译、公开能力审计、低保真候选比较与多轮视觉重校准，最终确认 `R1-P01 / 社区发现 / PC 1440`。该稿固定现代自然紧凑表面、非对称主次、连续扫描行、灰玉品牌、墨蓝操作和国风暖白，并将公共频道、成员公开动态、跨帖神评、帖子与问答并置为“社区正在发生”。
- `2026-08-04` 清理活动设计源中的旧 PC / mobile 和全部失败研究，只保留唯一正式 PC、`8` 个必要组件母版与主题变量；长期规范新增 R1-P01 视觉继承卡和获批后删除废稿规则。mobile 与统一公开读模型仍待下一轮，运行时代码、token 和 API 未修改。
- `2026-08-05` 在唯一活动设计源中完成并确认 `R1-P01 / 社区发现 / Mobile 390` 正式代表页：搜索与真实内容前置，参与动作进入精选讨论，社区脉搏、贡献者和知识主题分别嵌入首屏、中段与流后；首轮反馈后，“社区正在发生”从异色列表拼接重构为墨蓝焦点事件、连续编号轨道和嵌入式贡献者人物节点。没有缩放 PC 或把右栏机械堆叠；画板高度 `1547px`，节点检查无裁切、溢出或失效图标，`2x` 视觉自检通过，用户已确认。
- `2026-08-05` 为五类“社区正在发生”item 固定统一公开读模型：频道摘要显式 `DiscoverVisibility=Summary`、成员动态首批只来自公开 Wiki 首次发布、跨帖神评联动当前 Comment / Post 资格，帖子与问答复用既有公开契约；排序采用 snapshot cutoff 与稳定 keyset 游标，社区脉搏只统计公开频道和近 `24` 小时可重算聚合，首批完整 feed `no-store` 并在跨源失败时关闭。该设计批当时尚未修改运行时代码、迁移、token 或 API。
- `2026-08-05` 完成 `R1-P01` 成组实现：Channel 增加默认 Hidden 的匿名摘要字段、版本和 migration，Console 增加独立 `view / manage` 权限、精确租户治理与 append-only 事件；`PublicDiscover` 以当前权威数据合并五类 item，提供 snapshot 游标、纯文本白名单、`no-store` 和整流失败关闭。`@radish/http` 与 `/discover` 已改为只消费统一 feed，页面使用首条焦点事件、连续编号轨道、嵌入式贡献者和非对称洞察区。后端专题 `57`、Client 全量 `489`、Console 全量 `61` 项测试及前后端构建通过；本批未启动服务，PostgreSQL 条件用例与 Gateway 真实截图仍待阶段验收。
- `2026-08-05` 完成 `R1-P01` 阶段性运行态验收：应用 migration 后 Gateway、API、Auth 宿主检查通过；匿名与种子管理员登录回流、PC `1440 × 1000`、mobile `390 × 844`、`zh / en`、`default / guofeng`、真实链接、复制反馈和 Console 治理只读路径通过，页面无横向溢出。运行态同时修正后端 `long` 字符串序列化与前端计数 `number` 假设不一致导致的 i18n 资源键回显；Console 实际状态写入未在浏览器中提交，幂等、版本冲突、领域事件与写入契约继续由后端定向测试覆盖。

## 当前结论

- 上游灰玉仍只是通用参考默认；Radish 已独立确认灰玉、墨蓝与国风暖白为 `R1-P01` 产品方向。页面已使用现有灰玉 / 墨蓝语义 token，全局 `guofeng` 品牌 token 因影响全部页面族保留到共享主题批，不能把局部落地描述为全站换色。
- 既有公开 head、canonical、分享路径、四主题权益和业务写入口未改变；本批只新增 Channel 摘要治理路由 / 权限、统一匿名 feed 和对应页面读取。
- `/discover` 已从旧帖子主流改为服务端统一混合流，静态与运行态现共同约束单一 feed、连续轨道、稳定游标消费、真实跨入口链接和多视口可用性；`R1-P01` 已关闭，下一顺位进入 `R1-P02`，不回拉本专题继续扩张。
- 设计轨后续只编辑 `radish-web-family-ui-v1.pen`；获批页面保留唯一代表稿，失败方案由 Git 追溯，不新建并行 `.pen`。任何 `.pen` 修改仍需当前任务明确授权。
