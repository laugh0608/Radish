# F4-R R3-P04 Public Forum 浏览族实现

> 日期：2026-08-11
> 状态：正式代码、静态回归与 Gateway PC / Mobile 运行态验收已完成，批次关闭
> 范围：`/forum`、分类、搜索、标签、Question / Poll / Lottery 浏览流；不含详情、Revision、Compose 与 WebOS

## 1. 结论

`R3-P04` 已按 `R1-P01 + R2-P03` 的继承边界完成正式代码实现，继承成立，不需要升级为新的 R1 / R2，也没有修改 Pencil。

四类 Forum 浏览组件现统一使用“连续结果主轴—从属阅读上下文”：PC 保留非对称主列与窄侧栏；Mobile 按 DOM 顺序先展示筛选和结果，再展示辅助信息，分类、排序、时间范围、相关标签与分页使用受控横向滚动，页面和正文卡片不承担横向溢出。搜索、标签和类型流原先位于主内容末尾的阅读说明已移到从属侧栏；列表既有 Compose CTA 仍保持原登录与路由回流。

Gateway 成组验收关闭了本批运行态边界。浏览器复核中另修正两处标签页表现：有效标签不再重复公开浏览徽标或展示内部编码 slug；不存在标签的页面级标题保持稳定的“公开标签”，具体不可用原因只由状态卡表达，避免页面标题与状态卡重复。

## 2. 样式所有权

- 新增 `PublicForumBrowse.module.css` 承接 Forum 浏览族布局、密度、筛选、列表、分页、相关标签和响应式契约；只在该业务族内复用，没有建立万能 Public card / rail。
- 新增 `publicForumBrowseStyles.ts` 组合既有共享表面与 browse 专属样式，五个浏览消费者不再直接拥有详情 / Compose 样式入口。
- `PublicForumApp.module.css` 删除 browse 专属与残留响应式选择器，从 `1646` 行降至 `1185` 行；详情和 Compose 继续使用原模块，既有交互状态机未迁移。
- browse 模块为 `717` 行；两个文件均回到仓库单文件边界内，新增 CSS 只使用主题语义 token。

## 3. 保持不变的契约

- 分类、标签、关键词、时间范围、排序与分页仍由原 URL route state 驱动。
- 来源返回、公开 head、canonical、JSON-LD、sitemap 和登录回流未改动。
- 分类 / 标签上下文、相关标签、帖子、神评摘要与类型流仍保持原独立请求、竞态和局部失败边界。
- Tag 禁用 / 删除、搜索空词 / 空结果、类型专属字段和排序能力未被视觉层改写。
- 未新增 API、数据库、migration、权限、业务字段、排序类型、推荐模型、导航状态或系统文案。
