# 2026-11-14 停用 Pencil

根据所有者确认，Web / Console 和 Flutter 的旧 `.pen`、预览与评审记录原样保留，现行设计流程与回填任务解除 Pencil 依赖。R1 / R2 继续评审代表页或局部状态，可用 Penpot 或可编辑代码原型留证。R3 沿用已确认的结构与共享组件，并在实际运行页面复核 PC / mobile。

现行流程见[代表页设计协作流程](../frontend/pencil-representative-page-workflow.md)，历史源和基准范围见[设计源目录](../frontend/design-sources/README.md)。
