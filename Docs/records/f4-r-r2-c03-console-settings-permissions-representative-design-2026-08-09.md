## 1. 结论

- `R2-C03` 保持 R2，不升级为新的完整页面类型：继续继承 `AdminLayout`、Console 五项真实入口、R1-C01 高密度资源表面和 R1-C02 权限 / 冲突状态，只补权限矩阵、设置编辑、危险确认和 mobile 风险差异。
- PC 权限代表区固定为“角色上下文—权限矩阵—变更证据”：只读 Operator 没有写入表面；`System / Admin` 明确显示内建保护，不提供重命名、禁用、删除或保存授权入口。
- PC 系统设置代表区固定为“紧凑设置列表—当前设置编辑 / 确认—变更历史”：Low 使用轻量确认，Medium 必须展示完整 key、旧值 / 新值、影响范围、生效方式、修改原因和人工 key 复核。
- Mobile `390 × 844` 只表达响应式差异，并固定为三条直接任务流：角色目录选择角色、围绕当前角色读取分组权限、从设置列表选择 Low 项进入编辑底板；角色与权限仍只读，Medium 保持 PC-only，不在移动端降级为普通保存。
- Settings / Profile 只表现现有个人资料与安全设置，不进入 `console.*` 权限矩阵，也不借本批新增账户能力。

## 3. Mobile 与壳层边界

- Mobile 角色页、权限矩阵和系统设置分别维护为独立 `390 × 844` 顶层业务页面，不使用外部说明板、设备卡片或多页面合并容器；页面保留 Console 顶部品牌栏，底部直接实例化共享 `Component / Mobile Tab Bar`，沿用暖白表面、浅灰玉激活项、Lucide 图标与“总览 / 治理 / 交易 / 权限 / 更多”五项入口。角色 / 权限激活“权限”，系统设置激活“更多”，不建立隐藏全局导航的授权任务壳层。
- 角色结构只读页改为连续角色目录：先展示角色总量、内建数量与只读边界，再让用户从 `Content Operator / System / Admin` 进入“查看权限”；内建标记与查看动作分离，不渲染创建、编辑、启停、删除、保存或批量授权动作。
- 权限矩阵只读页改为当前角色详情：顶部提供返回角色目录，角色上下文显示身份与已允许数量，矩阵按“角色管理 / 系统设置”分组；每项同时展示完整技术 key、简短中文含义和“允许 / 未授予”结果，避免用户必须从键名猜测权限作用。无权限项使用真实空态，不把空集合伪装为读取错误。
- 系统设置页先提供真实搜索、分类与设置列表，点选 Low 项后在同页底部编辑层中填写值和变更原因；编辑层明确展示 dirty、离开再确认、有效范围、CAS 版本与 `409` 保留草稿边界。Medium 行只显示风险与 PC-only，不在 Mobile 出现确认或保存入口。
- `/console/settings` 与 `/console/profile` 只承接已有自服务能力；它们与 `/console/roles`、权限矩阵和 `/console/system-config` 的治理授权保持分离。

## 4. 必要关键状态

- **只读 Operator**：可查看受权角色 / 权限信息，不出现保存、启停、删除或批量动作；写请求不会从只读表面发起。
- **内建角色保护**：`System / Admin` 的重命名、禁用、删除与授权保存均明确锁定，并解释保护原因。
- **dirty / 离开保护**：保留原值与草稿值，离开前明确选择“留在页面”或“放弃并离开”，不静默丢弃草稿。
- **并发 `409`**：CAS 冲突时保留本地草稿，展示服务端当前值并提供比较 / 重新加载；不自动覆盖、不静默重试。
- **unavailable / stale**：结构化错误失败关闭；stale 数据标注读取状态，写入前仍由 CAS 校验，不暗示实时刷新。
- **真实空态**：权限项空、设置覆盖值空、变更历史空分别表达成功的空集合，与 unavailable、权限拒绝和 `409` 保持独立。
- **Medium 显式确认**：完整展示风险等级、完整 key、旧值 / 新值、影响范围、生效方式、修改原因和人工 key 复核，确认不完整时不得保存。

## 5. 契约与停止线

- 现有 API、权限、URL 与 LongId 字符串契约保持不变；授权与设置写入继续使用已关闭门禁后的单调版本、原子 CAS 和结构化 `400 / 409`。
- 角色授权、系统设置和审计继续服从既有事务与存储边界；设计不暗示跨存储事务、客户端合并提交或绕过服务端保护。
- 不新增权限种类、批量授权、审批流、High / Critical 设置、任意动态 key、实时刷新或新的移动壳层。
- 不把 Settings / Profile 纳入 `console.*`，不提前推进其他 R2 / R3 页面。
