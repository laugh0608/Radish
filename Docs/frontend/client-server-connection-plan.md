# 官方客户端、官方端点与自部署实例连接规划

状态：产品方向已确认；运行时实例选择尚未实施。

确认日期：2026-10-12（Asia/Shanghai）。

本文面向产品、Flutter、Web、认证与发布维护者，定义同一官方客户端连接不同 Radish 实例的产品要求、实施拆分与验收范围。具体发现协议、配置 schema、认证与存储迁移方案在实施前另行评审；本文不提供已上线端点或可执行部署配置。

## 已确认的产品方向

同一平台、同一正式发布渠道的同一个官方客户端安装包，必须支持连接官方端点和用户自部署的兼容 Radish 后端。用户在客户端运行时选择“官方服务”或“自部署服务器”，填写并保存实例入口即可，无需修改源码、重新编译、重签名或下载实例专用安装包。

官方端点是正式产品交付目标；真实域名、开放时间、运营资源与服务范围在发布专题中确认。服务尚未开放时应说明状态并允许配置自部署入口，不能把示例域名当作官方服务，也不能静默连接其他实例。自部署实例的核心社区路径不以官方端点在线为前提。

官方与自部署是部署归属选择，不是互相联通的社区。账户、内容、权限、资产和治理均归各自实例；连接选择不自动实现联邦、跨实例登录、数据迁移或内容合并。第三方重写后端的兼容支持需另行定义，本规划首先覆盖官方服务端的兼容自部署版本。

## 客户端与 Web 的分工

- Flutter Native 承担安装包内的运行时服务器选择。API、Auth、实时连接和公开链接由选定实例的已验证入口派生，沿用 Gateway 统一公开入口，不建立第二套业务后端。
- Web 支持同一官方前端构建产物在官方或自部署实例域名下运行，部署时以公开运行配置连接本实例，无需按域名重新编译；页面、登录和 API 沿用实例同源边界。
- 浏览器访问自部署实例的 Web 入口即可使用该实例。官方托管 Web 跨域携带认证请求连接任意后端不属于本次确认，不以新增 credentialed CORS 代替原生服务器选择。
- Console、WebOS 与 Tauri 不因本规划新增原生产品线或跨实例管理能力。既有 Web-first、Flutter 次级与平台阶段门槛继续有效。

## 连接与切换流程

1. 首次进入或未登录时展示当前服务归属、服务器选择与自部署地址输入；离开选择页前验证地址和兼容性。
2. 在发送登录凭据前，以不含凭据的有界请求确认实例身份、协议兼容性、可用能力与认证入口。发现信息不能任意改变目标 origin 或取得其他实例的 Token。
3. 按选定实例发起 OIDC；认证尝试绑定实例、回调和请求代次，完成后进入该实例的社区内容。界面持续可查看当前实例。
4. 切换前处理未保存编辑及未完成操作，终止旧实例的活动请求、实时连接与认证尝试；切换失败保留明确可恢复状态，不静默返回官方端点。
5. 新实例重新建立自己的会话。旧请求、冷启动回调、深链、最近阅读和通知只在所属实例消费；同名用户和相同对象 ID 不足以跨实例复用状态。

会话、安全存储键、缓存、最近入口和待处理动作必须按已验证实例及账户隔离。OIDC 账户继续依据 issuer 与 subject 识别，但相同身份提供方不授予另一实例的业务权限，也不允许重用不适用于目标实例的访问凭据。

切换不是迁移。原实例内容、钱包和权限不随地址变化搬走；迁移需独立确认。旧单实例本地状态升级时只能绑定其已知原实例，不能自动归给新选中的服务器。

## 兼容性与连接安全

客户端与服务端需给出协议版本、最低兼容范围、能力缺失、维护和认证不可用的可解释结果；具体发现路由与字段尚未冻结。自部署版本落后时明确拒绝不兼容操作，不要求每次更换域名就构建新客户端。

正式远端使用经验证的 HTTPS。局域网 DNS / IP、端口、证书信任与回调策略在实现前单独冻结，不用普遍忽略证书错误支持自部署。地址规范化、重定向、跨 origin 凭据、请求超时与响应上限须覆盖负向验收。

## 当前事实与实施顺位

现有 Flutter 从 `RADISH_ENVIRONMENT` / `RADISH_GATEWAY_BASE_URL` 的 `--dart-define` 编译期输入确定目标，testing / production 还有 DNS / HTTPS 与证书限制；它是构建环境配置，不是本规划的用户运行时选择。Web 镜像已有 `RADISH_PUBLIC_URL` 运行配置能力，也不证明 Native 已支持切换。

本次仅更新规划，不改 Dart / TypeScript / C#、配置、OIDC 注册、存储或网络策略。当前日志治理和 P8 平台建设顺位由[当前进行中](../planning/current.md)维护。本能力进入独立客户端专题后按以下切片推进：

1. 冻结实例标识、兼容发现、地址 / TLS 与认证入口合同，评审现有单实例安全存储和持久状态的迁移。
2. 实现运行时实例配置、登录前选择、连接状态和认证绑定；完成旧请求 / 回调隔离。
3. 接通私域缓存、通知 / 实时连接、深链、公开链接、重启与切换恢复。
4. 在同一候选安装包上验收官方和自部署实例，分别完成官方运营与自部署安装 / 升级 / 备份交付。真实服务、签名与分发按对应任务授权。

## 验收标准

- 同一个未改动的候选安装包连接两个独立兼容实例并完成登录、读取、参与、退出和重启恢复；不得改构建参数或使用不同二进制代替切换。
- 官方与自部署路径按实际开放范围分别取得真实目标证据；官方尚未上线可独立验收自部署路径，未验收一侧明确标记未开放。完整双端点交付需两侧证据，两个测试实例只证明客户端机制。
- 旧实例凭据、私域缓存、相同对象 ID、延迟响应、OIDC 回调与通知不会进入另一实例；切换期间未保存内容有明确处理结果。
- 官方服务不可用时仍可选择兼容自部署实例；地址 / TLS / 协议错误有可理解提示，且不向错误目标发送凭据。
- 每个声明支持的平台独立验收；本规划不把现有 Android、iOS 或 macOS 的单实例运行证据升级为多实例完成。
